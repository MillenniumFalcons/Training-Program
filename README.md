# Team 3647 Programming training 
Welcome! This training is made up of 7 steps, which will guide you from 0 code experience to becoming an expert in FRC programming.

This training program is designed for you to work on at your own pace. I (current head of programming) don't expect you to do all of this on your own, you will likely need my help at some point. Please do not hesistate, to ask for help. If you intend to contribute to our team's code, you will need to build a connection with me anyways, so it's a good idea to ask me or another assistant head for help.
